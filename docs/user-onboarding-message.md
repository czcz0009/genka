# テストユーザー向け案内メッセージ(CrowdWorks/LINE等にそのまま貼る用)

CrowdWorks経由のテストユーザーに送る、ツールの使い方クイックスタート案内。
プレーンテキストとしてそのまま貼り付けられる想定(Markdown記法は使っていない)。
`[ ]`の部分は送る前に自分の情報に置き換える。

---

【原価計算ツールのご案内】

このツールは、メニューごとの原価率(仕入れ値に対して売価が適正か)を自動で計算し、値上げを検討すべきメニューを教えてくれる無料ツールです。

■ 始め方
1. こちらからアクセスしてください:[ツールのURL]
2. 「新規登録」からメールアドレスとパスワードを登録すると、そのまま使い始められます

■ 使い方(最初の2ステップ)
1. メニューを登録する
　ログイン後、画面の案内に沿って「メニューを登録」します。Excelやスプレッドシートで管理している表があれば取り込みも使えますが、無ければ手入力で1品1分ほどで登録できます。

2. 原価率を確認する
　メニューを登録すると、「原価計算」の一覧画面に、メニューごとの原価・原価率が自動で表示されます。目標より原価率が高いメニューは色が変わってひと目で分かります。

■ その他
・初回ログイン時に、画面の使い方を案内する簡単なツアーが自動で始まります(あとで見返したい場合は「設定」画面の「案内をもう一度見る」から)
・各画面の「?」マークを押すと、その機能の説明が読めます
・分からないこと・気づいたことがあれば、遠慮なく[連絡先]までご連絡ください
