# PR動画(Instagramリール・X・LP用)の絵コンテと撮影の段取り

作成: 2026-10-23 / 状態: **絵コンテ確定・撮影の準備まで済み。撮影はまだ**(撮影は2026-10-28までが目安)
読む人: Mahiro本人、および撮影を進める次のClaude Codeセッション

## 方針(Mahiro確定)
- 長さ45秒前後、縦型 9:16(1080×1920)。主な載せ場所はInstagramのリール。XとLPにも同じものを使う。
- 声なし、字幕中心。BGMはMahiroが仕上げで足す。
- 締めの一言(確定): **「知らないうちに減っている利益に、気づける。」**
- 伝え方: 痛み(原価計算も仕入れ値の管理も、面倒で続かない)→ 方法(計算も更新もツールにまかせられる)→ 範囲(人件費・家賃・ロスまで含めた、お店全体の数字)。野菜・肉の市場のお知らせは主役ではなく、強みの1つ。
- 使わない表現: 「利益を守ります」(結果を約束するため)、「人件費の計算ができる」(人件費は入力してもらう作りで、給与計算やシフト管理はしないため)、誇張した表現(「必ず利益が上がる」など)。

## 守る条件
- 字幕の数字は、**撮影の日に画面に実際に出ている値だけ**を使う(下の表の数字は2026-10-23時点の仮の値)。
- アラートを、店の仕入れ値そのものの値上がりのように見せない(「市場の値上がり」「試算」と分かる文言にする)。
- 市場価格が映る場面には、画面の下に小さく出典を入れる: 「出典: 農林水産省「青果物卸売市場調査(旬別結果)」「畜産物卸売価格の推移」をもとに当サービスが加工・試算した参考値。国(農林水産省)が内容を保証するものではありません。」
- 全場面に小さくデモの表示: 「※画面は架空の店舗のデモデータです(2026年10月時点の市場価格)」
- デモ用のアカウントとデータだけを使う。メールアドレスやIDを映さない。
- 字幕は、リールでボタンや説明文に隠れない位置に置く(上の約14%=〜270pxと、下の約35%=1250px〜、右端のボタンの列を避ける)。
  - 大きい字幕: 上から300〜620pxの帯(半透明の濃い背景に白い文字、左右80px・右は160pxの余白)
  - 小さい注記・出典・デモの表示: 上から1150〜1240px
  - アプリの画面は全面に映し、強調したい行は650〜1150pxに来るようにスクロールする
- 撮影は**2026-10-28まで**が目安。10/29の野菜の取得で比べる旬が変わり、キャベツのアラートが消える可能性がある。10/29以降になったら、6場面目を当日アラートに出ている品目に差し替える。

## 撮影の段取り
1. **デモのアカウントを作り直す**(ロス入りのデータにし、納品書の読み取り回数も元に戻すため)。
   - 作る: `SEED_PRESET=teishoku node --env-file=.env.local scripts/demo/seed_demo.mjs <パスワード>`(店名「定食処 こはる亭」。中身は `scripts/demo/presets.mjs`)
   - ログイン情報は**チャットに出さず、手元のファイルにだけ保存**する(リポジトリの外。例: `C:\Users\<ユーザー>\genka-demo\pr-demo-login.txt`)。
   - 古いPR用アカウントは、IDを指定して削除し、0件を確かめる(下の「今あるPR用アカウント」)。
2. **デモの納品書の画像を作る**: `node scripts/demo/make_pr_invoice.mjs <出力先.png>`(宛先「定食処 こはる亭 御中」、取引先「こもれび青果株式会社」、住所・電話なし、「見本」の印と透かし。品目はデモに登録済みの野菜5つ・同じ単位)。
   - 2つの名前は、2026-10-23に国税庁法人番号公表サイト(部分一致・閉鎖等を含む)で「該当するデータが存在しません」を確認済み(対照の「トヨタ自動車」は80件)。
3. **撮り方**: スマホ幅 360×640 を3倍の細かさ(deviceScaleFactor 3)で撮ると1080×1920ちょうどになる(拡大しないので文字がにじまない)。普通の録画ではなく、1コマずつ高画質の画像で撮り(コマ撮り)、ffmpegで30コマ/秒の動画にする。
4. **場面2を最初に撮る**: 納品書の読み取りは1回だけ行い(成功3回までの上限を使うため)、そのコマを使い回す。保存するとデモの単価が変わる(キャベツ150円→180円など)ので、**場面3〜6は保存の後に撮り**、字幕の数字も保存後の画面から取る。
5. 撮影が終わったら、Mahiroの指示でデモのアカウントを削除し、ログイン情報のファイルも消す。
